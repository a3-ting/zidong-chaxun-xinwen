# 自动查询新闻

全国 & 湖南省热点新闻仪表盘

## 功能

- 自动展示全国热点新闻（人民日报、新华社、中国政府网等）
- 展示湖南省要闻（湖南省政府网、长沙晚报等）
- 每 30 分钟自动刷新
- 支持手动导入/导出 JSON 数据
- 纯静态页面，无需后端服务

## 文件说明

| 文件 | 说明 |
|------|------|
| `hot-news-dashboard.html` | 主页面，热点新闻仪表盘 UI |
| `news-proxy.js` | 新闻数据代理服务（Node.js） |

## 部署方式

直接双击 `hot-news-dashboard.html` 即可在浏览器中打开使用，无需服务器。

如需实时数据刷新，需搭配 `news-proxy.js` 运行本地代理服务。

## 技术栈

- 前端：HTML + CSS + JavaScript（纯静态）
- 数据源：人民日报、新华社、中国政府网、央广网、湖南省政府网等公开接口
